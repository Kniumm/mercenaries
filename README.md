# Description
Adds a new villager-based faction to the Overworld, whose mercenaries can be recruited by both villages and players.

## Mercenary
A recruitable warrior.

- Attacks illagers, witches and zombies.
- Retaliates against hostile players.
- Can and will attack in groups.
- Can wear iron armor and sometimes bear the Allegiance Banner.
- Uses either a Iron Sword, an Iron Axe or a Crossbow.
- It will sometimes use a Shield / Allegiance Shield along with its main melee weapon.

## Barracks
A small building housing the Mercenaries employed by the village.

- Generates in villages.
- 10 mercenaries spawn per barracks.

## Allegiance Banner
A banner representing the mercenaries' Company.

## Allegiance Shield
A Shield with the Allegiance Banner pattern applied on it.
